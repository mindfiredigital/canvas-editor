## Become a Contributor

We welcome new contributors of any experience level.

1. Read the [How to Contribute](./how-to-contribute) guide.
2. Review the [Code of Conduct](./code-of-conduce).
3. Pick a [good first issue](https://github.com/mindfiredigital/canvas-editor/labels/good%20first%20issue).
4. Open a PR — your name lands on the GitHub contributors list automatically.

Thanks to everyone who has contributed.
